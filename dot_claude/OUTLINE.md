# Use Outline MCP tools to create durable records for memories and journals

- Memories + Journal → Personal collection (`ace54f9c-91d2-4d17-bf17-f503e63326c0`, private)
- Ideas → Resources collection (`ab5099b4-17a3-49e6-9b0c-b9792435a2d3`), under the "Ideas" parent
  doc

## Create memories / journals / ideas when

If it's documentation (how something got fixed) or troubleshooting (how to fix something), a
reference documentation for tools/process, recording important decisions, or other reusable
knowledge, use the Personal collection and create a memory.

If it's capture project ideas or features, brainstorming solutions, noting stuff to investigate,
asking what if questions, create an idea under the Ideas parent doc in Resources.

If I'm documenting something that happened during a day / specifically dated, create a journal entry in the Personal collection. "Journal" parent doc → YYYY-MM-DD child doc → `##` sections per topic.
